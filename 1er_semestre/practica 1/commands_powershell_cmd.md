# Comandos usados en las clases

## PowerShell

| # | Comando | Categoría | Uso típico |
|---|---------|-----------|------------|
| 1 | `Get-ChildItem` | CRUD de archivos / carpetas | Listar archivos y directorios |
| 2 | `New-Item` | CRUD de archivos / carpetas | Crear archivos o carpetas |
| 3 | `Remove-Item` | CRUD de archivos / carpetas | Eliminar archivos o carpetas |
| 4 | `Set-Item` | CRUD de archivos / carpetas | Modificar atributos o contenido |
| 5 | `Get-Process` | Gestión de procesos | Obtener lista de procesos activos |
| 6 | `Stop-Process` | Gestión de procesos | Finalizar procesos problemáticos |
| 7 | `Get-Service` | Servicios del sistema | Consultar estado de servicios |
| 8 | `Start-Service` / `Stop-Service` | Servicios del sistema | Iniciar o detener servicios |
| 9 | `Get-EventLog` | Auditoría / forense | Recuperar eventos del Visor de Eventos |


## CMD (línea de comandos de Windows)

| # | Comando | Contexto de uso en la clase |
|---|---------|------------------------------|
| 6 | `bcdedit` | Configuración del boot loader de Windows |
| 7 | `netstat` | Consulta de conexiones de red durante diagnóstico de telemetría |
| 8 | `resmon.exe` | Abrir el Monitor de Recursos para diagnosticar CPU, RAM, disco y red |
| 9 | `type` | Visualizar contenido de archivos de texto |
|10| `notepad` | Abrir el editor de texto para inspeccionar archivos |
|11| `cls` | Limpiar la pantalla de la consola |
|12| `exit` | Cerrar la ventana de CMD |
