# Cuestionario Kahoot: Herramientas del Sistema Operativo

Este cuestionario de 12 preguntas está diseñado para repasar la utilidad y el contexto de uso de cada una de las herramientas del sistema operativo que los alumnos utilizaron durante las prácticas.

---

### Preguntas y Respuestas (Formato Kahoot)

#### 1. ¿Qué herramienta gráfica de Windows permite modificar el "ADN" del sistema cambiando claves y valores de configuración?
* **A (Rojo):** Editor del Registro (`regedit.exe`) **[CORRECTA]**
* **B (Azul):** Administrador de Dispositivos
* **C (Amarillo):** Monitor de Recursos
* **D (Verde):** Propiedades del Sistema

#### 2. Para diagnosticar en tiempo real qué proceso está saturando la CPU, el Disco o consumiendo red, la mejor herramienta es:
* **A (Rojo):** Visor de Eventos
* **B (Azul):** Monitor de Recursos (`resmon.exe`) **[CORRECTA]**
* **C (Amarillo):** Monitor de Confiabilidad
* **D (Verde):** Consola de Servicios

#### 3. ¿Qué herramienta gráfica te muestra una línea de tiempo del 1 al 10 con la estabilidad de tu PC y el historial de fallos?
* **A (Rojo):** Monitor de Confiabilidad (`perfmon /rel`) **[CORRECTA]**
* **B (Azul):** Visor de Eventos
* **C (Amarillo):** Administrador de Tareas
* **D (Verde):** Símbolo del Sistema

#### 4. Para auditar y buscar registros (logs) de seguridad, accesos o errores del Kernel de Windows, se debe abrir el:
* **A (Rojo):** Monitor de Rendimiento
* **B (Azul):** Bloc de Notas
* **C (Amarillo):** Visor de Eventos (`eventvwr.msc`) **[CORRECTA]**
* **D (Verde):** panel de Control clásico

#### 5. ¿Qué utilidad de línea de comandos de Windows permite configurar y consultar el almacén de datos de arranque (BCD)?
* **A (Rojo):** `regedit`
* **B (Azul):** `bcdedit.exe` **[CORRECTA]**
* **C (Amarillo):** `netstat`
* **D (Verde):** `sysdm.cpl`

#### 6. Escribir "sysdm.cpl" en la ventana Ejecutar (Win + R) abre directamente:
* **A (Rojo):** Las Propiedades del Sistema (Rendimiento/Variables) **[CORRECTA]**
* **B (Azul):** La Consola de Servicios
* **C (Amarillo):** El Editor del Registro
* **D (Verde):** El Visor de Eventos

#### 7. ¿Qué panel del sistema permite detener, iniciar o deshabilitar procesos de fondo que no tienen interfaz gráfica?
* **A (Rojo):** Administrador de Tareas
* **B (Azul):** Servicios (`services.msc`) **[CORRECTA]**
* **C (Amarillo):** Monitor de Recursos
* **D (Verde):** Propiedades del Sistema

#### 8. ¿Qué consola moderna de comandos utiliza scripts con extensión `.ps1` y permite administrar recursos como objetos?
* **A (Rojo):** CMD (Símbolo del sistema)
* **B (Azul):** Bash
* **C (Amarillo):** Windows PowerShell **[CORRECTA]**
* **D (Verde):** Telnet

#### 9. El intérprete de comandos clásico de Windows (CMD) se utiliza principalmente en las prácticas para:
* **A (Rojo):** Automatizar con pipelines complejos y objetos
* **B (Azul):** Compatibilidad y ejecución de comandos tradicionales **[CORRECTA]**
* **C (Amarillo):** Modificar directamente el registro del Kernel
* **D (Verde):** Ver el historial de estabilidad gráfica

#### 10. Si un programa se ha colgado y deseas finalizar su proceso rápidamente desde una interfaz visual de lista, usas:
* **A (Rojo):** Administrador de Tareas (`taskmgr.exe`) **[CORRECTA]**
* **B (Azul):** Bloc de Notas
* **C (Amarillo):** Visor de Eventos
* **D (Verde):** Monitor de Confiabilidad

#### 11. ¿Qué editor básico del sistema se utiliza para examinar archivos de registro `.reg` o escribir scripts rápidos?
* **A (Rojo):** Wordpad
* **B (Azul):** Microsoft Word
* **C (Amarillo):** Bloc de Notas (`notepad.exe`) **[CORRECTA]**
* **D (Verde):** Paint

#### 12. ¿Qué proceso del sistema operativo se encarga de la composición visual de las ventanas y genera carga gráfica?
* **A (Rojo):** `dwm.exe` (Desktop Window Manager) **[CORRECTA]**
* **B (Azul):** `explorer.exe`
* **C (Amarillo):** `svchost.exe`
* **D (Verde):** `spoolsv.exe`
